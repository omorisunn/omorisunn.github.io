这是一篇占位文章。它没有要表达的观点，只负责把排版撑开，让首页、列表页和文章页都能被检查。

## 为什么需要示例文章

真实内容还没准备好时，空页面很容易掩盖问题。段落长度、标题层级、目录高亮和代码块宽度，都需要一段足够长的文字才能看出来。

> 好的界面不会抢走注意力，它只是让内容更容易被读完。

这句话和这篇文章没有关系，它只是用来检查引用样式。

## 一段代码

~~~tsx
type GlassProps = {
  blur: number;
  saturation: number;
};

export function Glass({ blur, saturation }: GlassProps) {
  return (
    <div
      style={{
        backdropFilter: "blur(" + blur + "px) saturate(" + saturation + "%)",
      }}
    />
  );
}
~~~

代码块右上角有一个复制按钮。点击后，按钮会短暂显示「已复制」。

## 这是一段很长很长的小标题，用来检查目录换行和正文层级是否依然清楚

标题变长时，目录不应该被撑破，正文也不应该失去节奏。这个段落继续提供一些普通文字，让页面看起来像一篇文章，而不是一组组件。

### 一个小节

小节的标题会缩进一级。它仍然属于目录，但视觉重量比二级标题轻。
